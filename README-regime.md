# 局勢總覽（資金輪動＋恐慌儀表）

網頁最上方的「局勢總覽」把三個時間尺度放在一起：

| 卡片 | 回答什麼 | 資料檔 | 誰產生 |
|---|---|---|---|
| 開盤前訊號 | 今天開盤要不要調部位 | `data/correlations.json` | `market_corr.py`（每天 07:30） |
| 資金輪動 | 資金在成長股還是防禦股 | `data/rotation.json` | ETF-Tracker2 的 `Etf_tracker_v2.py`（每晚 20:00） |
| 恐慌儀表 | 跌勢是否接近尾聲 | `data/panic.json` | `panic_gauge.py`（每天 07:30） |

最上面一行是綜合判讀（例如「資金強烈防守＋恐慌升溫 → 暫不進場」、「資金防守＋恐慌退燒 → 可先布局 1/3」）。

## 恐慌儀表規則

| 指標 | 恐慌 | 退燒 |
|---|---|---|
| 波動度（台指VIX，未滿120天前用加權指數10日實現波動率） | ≥ 近120日第90百分位 | 從10日高點回落20%以上且跌破5日均 |
| 外資台指期淨空單 | ≥ 近120日第80百分位 | 從10日高點減少25%以上 |
| 上市融資餘額 | 10日減少4%以上 | （近15日內大減過＝籌碼已洗） |

狀態：平靜 → 警戒（1項恐慌）→ 恐慌升溫（2項以上）→ 融資斷頭 → 恐慌退燒（近15日曾升溫＋波動回落或空單回補＋融資已洗）。

**融資斷頭**：上市融資 10 日減少 15% 以上，觸發後 5 個交易日內顯示。回測兩次（2025/4/8、2026/7/29）都在最低點前 1 天，
觸發後最多再跌約 6%。用法是小量試單約 1/5、停損設在觸發日低點下方；斷頭後若恐慌又升溫，網頁會提示試單續抱、等退燒再加碼。

進場三段：融資斷頭 → 試單 1/5；恐慌退燒 → 加到 1/3；資金輪動轉攻 → 加滿。

「放寬退燒條件」測試過（回落10%/回補15%、取消融資條件、單項恐慌即可），訊號沒有提早，只增加假訊號，所以維持原設定。
門檻在 `panic_gauge.py` 最上面。

## 第一次使用

```bat
python panic_gauge.py --probe     :: 測試期交所、證交所三個來源抓不抓得到
python panic_gauge.py             :: 第一次補約兩年歷史（融資逐日抓，約 10 分鐘），之後每天幾秒
```

`run_market_corr.bat` 已經加入 `panic_gauge.py`，排程不用改。

## 限制

- 台指VIX官方檔只保留近4個月，所以從現在開始逐日累積；滿120天前用實現波動率代替，網頁會註明。
- 融資：上市（證交所）＋上櫃（櫃買中心）。上櫃第一次要補約兩年歷史（約 10 分鐘）；補齊前先只用上市，網頁會註明。執行時也會列出「上市單獨」「上櫃單獨」斷頭的時間，比較哪個先觸發。
- 回測只有約兩年、兩三次急跌，樣本少，看方向不看精確數字。
